# OpenCoWork runtime attribution

The `OpenCoworkRuntimeLoop` is an adaptation of the Agent loop structure from
the OpenCoWork project. OpenCoWork is distributed under the Apache License,
Version 2.0. The original project license is retained at `OpenCowork/LICENSE`.

This CxShell adaptation is intentionally limited to the runtime loop. It does
not include the OpenCoWork application, Worker process, provider clients,
browser tools, or UI integrations.
